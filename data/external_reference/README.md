# External reference data (verified university information)

This folder is for **verified** information only: official schools, programmes, academic calendar, grading and academic-standing policy, fee schedules and so on. It is empty at the moment.

Each file placed here must state its source (document title or URL), the date it was verified and who verified it. Rows loaded from here get `data_source = EXTERNAL_REFERENCE` and `verification_status = VERIFIED`, and replace the matching PLACEHOLDER rows in `data/synthetic/reference/`.

The list of needed items is in `SCHEMA_PROPOSAL.md` §10 (V1–V16).
